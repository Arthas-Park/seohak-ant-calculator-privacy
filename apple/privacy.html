2. Apple 인앱결제

배너 영구 제거 상품 com.shmini.tethercalculator.remove_banner의 조회·구매·복원은 Apple StoreKit을 이용합니다. Apple이 계정·결제수단·거래 처리를 담당하며 운영자는 카드 번호나 Apple 계정 비밀번호를 받지 않습니다.

앱은 Apple이 검증한 거래의 상품·구매·취소 상태를 기기에서 확인하여 배너 표시 여부를 결정합니다. 이 거래 정보를 운영자의 서버로 전송하거나 별도 데이터베이스에 저장하지 않습니다. 구매 기록은 Apple이 해당 정책과 법령에 따라 관리합니다.

동일한 Apple 계정으로 구매를 복원할 수 있습니다. 앱의 로컬 정보 삭제와 Apple 계정의 구매 기록 삭제는 별개입니다. 환불은 Apple 환불 요청 절차를 이용할 수 있습니다. Apple 개인정보처리방침

3. 자동 환율 조회 및 호스팅

자동 환율이 켜져 있으면 앱은 https://seohak-ant-rates.arthas-p.chatgpt.site/latest-rate.json에서 공개 기준환율 파일을 HTTPS로 조회합니다. 요청에는 입력 금액·계산식·계산 결과·계정 정보·광고 식별자 또는 고유 기기 식별자를 넣지 않습니다. 앱 식별 문자열(User-Agent)은 모든 이용자에게 공통이며 쿠키를 저장하거나 사용하지 않습니다.

파일 전송과 서비스 보안·장애 대응을 위해 IP 주소, 접속 시각, 요청 경로, User-Agent 등 기술 통신정보가 호스팅 제공자에게 전달되거나 기록될 수 있습니다. 운영자는 별도의 계산 내역 서버·이용자 데이터베이스·행동 분석 기능을 운영하지 않습니다.

호스팅 통신정보는 서비스 제공·보안 및 법적 의무 이행에 필요한 기간 동안 제공자의 정책과 적용되는 계약에 따라 보관·파기됩니다. 운영자는 해당 인프라 기록에 별도의 고정 보관기간을 설정하지 않습니다. 관련 처리·보호·삭제 기준은 OpenAI 데이터 처리 부속약정과 Cloudflare 개인정보처리방침에서 확인할 수 있습니다. 환율 파일 제공이 끝나는 즉시 모든 통신기록이 삭제된다는 의미는 아닙니다.

환율 화면에서 ‘자동 환율’을 끄고 저장하면 이후 자동 조회를 중단할 수 있습니다. 수동 환율로 계산기를 계속 사용할 수 있습니다.

이 개인정보처리방침과 지원 페이지는 GitHub Pages에 게시됩니다. 이용자가 페이지를 열면 GitHub는 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 앱의 자동 환율 조회와는 별도의 웹페이지 접속입니다. 페이지에는 운영자가 추가한 광고·행동 분석 스크립트나 입력 폼이 없습니다. GitHub Pages 수집 안내, GitHub 개인정보처리방침

이용자가 문의 이메일을 보내면 발신 주소와 직접 제공한 문의 내용은 문의 확인·답변에 사용됩니다. 답변에 필요하지 않은 계좌 비밀번호, 카드 번호 또는 거래소 로그인 정보는 보내지 마세요. 문의 정보는 처리 목적이 달성되면 삭제하되, 법령상 보관 의무나 분쟁 대응을 위해 필요한 경우 해당 사유가 유지되는 동안 보관합니다. 문의와 관련한 열람·정정·삭제 요청도 같은 이메일로 보낼 수 있습니다.

5. 로컬 정보 삭제 및 선택권

현재 계산은 C 버튼으로 초기화할 수 있습니다. 자동 환율 사용 여부는 환율 화면에서 변경할 수 있습니다.

  • iPhone: 설정 → 일반 → iPhone 저장 공간 → 서학개미 계산기 → ‘앱 삭제’를 선택하면 앱과 기기에 저장된 앱 데이터가 삭제됩니다. ‘앱 정리하기’는 데이터를 남기므로 다릅니다.
  • Mac: 앱을 완전히 종료하고 삭제한 뒤, Finder의 이동 → 폴더로 이동에서 ~/Library/Containers/를 엽니다. 이 앱의 전용 폴더 com.shmini.tethercalculator를 휴지통으로 이동하면 앱의 로컬 설정·계산 상태·환율 캐시를 제거할 수 있습니다. Finder가 앱 이름을 대신 표시할 수 있으므로 폴더의 정보 가져오기에서 이름을 확인합니다. 다른 앱의 폴더는 삭제하지 않습니다. 앱 본체를 삭제하는 것만으로 설정이 모두 제거되는 것은 아닙니다.

운영체제나 백업 서비스에 보관된 사본은 해당 서비스에서 별도로 관리합니다. Apple 계정의 구매 기록은 로컬 삭제 후에도 남을 수 있으며, 재설치 후 같은 계정으로 구매 복원을 할 수 있습니다.

호스팅 정보 또는 문의 정보에 관한 열람·정정·삭제·처리 제한 요청은 아래 연락처로 보낼 수 있습니다. 운영자는 요청 범위와 관련 법령에 따라 조치하며, 필요한 경우 해당 제공자의 권리 행사 절차를 안내합니다.

6. 보호 조치

앱은 Mac App Sandbox와 HTTPS 통신을 사용합니다. 자동 환율 파일은 크기·형식·전자서명·기준일·버전을 검증한 뒤 환율 값으로만 사용합니다. 수신한 파일을 코드로 실행하지 않으며 검증에 실패하면 해당 값을 적용하지 않습니다. 구매 권한은 Apple이 검증한 거래로 확인합니다.
