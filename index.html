개요

afnitel(이하 “운영자”)은 서학개미 계산기(부제: 코인개미 계산기, 이하 “앱”) 이용자의 개인정보를 중요하게 생각하며 관련 법령을 준수합니다. 이 방침은 앱에서 처리되는 정보와 이용자의 권리를 설명합니다.

핵심 안내
앱은 회원가입 없이 사용할 수 있습니다. 입력 금액, 계산식 및 계산 결과는 기기 안에서 처리되며 외부로 전송되지 않습니다. 자동 환율이 켜져 있으면 공개된 환율 파일을 인터넷으로 조회합니다.

자동 환율 관련 내용은 앱 1.7 버전부터 적용됩니다. 1.6 버전은 자동 환율 파일을 조회하지 않습니다.

1. 앱의 기본 처리 원칙

앱은 연락처, 위치, 사진, 마이크, 카메라 또는 Android 광고 식별자(Advertising ID)에 접근하지 않습니다. 결제수단 정보도 운영자가 직접 수집하거나 저장하지 않습니다.

3. ONE Store 인앱결제 과정에서 처리되는 정보

앱은 remove_banner 상품의 조회·구매·구매 확인 및 구매 권한 복원을 위해 ONE Store 인앱결제 SDK를 사용합니다. 이 과정에서 ONE Store가 다음 정보를 처리할 수 있습니다.

  • ONE Store 계정 및 결제 처리 정보
  • 앱 패키지·버전과 상품 ID(remove_banner)
  • 주문·구매 상태, 구매 토큰 및 구매 확인 상태
  • 결제 요청 식별값, SDK 응답, 오류 및 부정 결제 방지에 필요한 정보

앱은 ONE Store가 반환한 구매 상태를 확인해 하단 자체 후원 카드의 표시 여부를 결정합니다. 신용카드 번호 등 결제수단 정보는 ONE Store가 처리하며 운영자가 직접 수집하거나 저장하지 않습니다.

4. 외부 광고 관련 정보

앱은 외부 광고를 표시하지 않으며 광고 SDK나 광고 미디에이션을 포함하지 않습니다. 맞춤형 광고, 광고 성과 측정 또는 광고 프로파일링도 수행하지 않습니다.

화면 하단의 개발자에게 치즈버거 사주기는 외부 광고가 아니라 앱 내부의 자체 후원 안내 카드입니다. 이 카드는 이용자 정보를 수집하거나 외부 광고 요청을 보내지 않습니다. 구매하지 않아도 계산기 기능은 모두 사용할 수 있으며, 구매 시 이 카드만 영구적으로 숨겨집니다.

5. 외부 서비스 이용과 국외 처리

운영자는 이용자의 개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 앱에 이용행태 분석 기능을 넣지 않으며, 운영자 별도의 이용자 접속 기록이나 이용자 데이터베이스를 만들지 않습니다.

자동 환율 조회

자동 환율이 켜져 있을 때 앱은 https://seohak-ant-rates.arthas-p.chatgpt.site에서 환율 파일을 HTTPS GET 방식으로 조회합니다. 요청에는 입력 금액, 계산식, 계산 결과, 계정 정보 또는 기기 식별자를 포함하지 않습니다. User-Agent는 모든 이용자에게 공통인 앱 식별 문자열입니다.

파일 전송과 서비스 보안·장애 대응을 위해 IP 주소, 접속 시각, 요청 경로, User-Agent 등 기술적인 통신정보가 호스팅 제공자에게 전달되거나 기록될 수 있습니다.

OpenAI의 공개 수탁사 목록에는 Cloudflare의 웹 호스팅 처리국가가 미국으로 기재되어 있습니다. 콘텐츠 전송·보안 처리는 이용자와 가까운 CDN 거점 등에서도 이루어질 수 있습니다. 제공자 및 처리 위치에 관한 정보는 OpenAI 수탁사 목록과 Cloudflare 개인정보처리방침에서 확인할 수 있습니다.

앱의 환율 설정에서 자동 환율을 끄면 이후 자동 환율 조회를 중단합니다. 직접 입력한 환율로 계산기를 계속 사용할 수 있습니다.

결제 및 공개 안내 페이지

ONE Store 인앱결제를 이용하면 결제 수행과 구매 권한 확인을 위해 이용자와 ONE Store 사이에서 결제 정보가 처리됩니다. 해당 처리는 ONE Store의 정책에 따릅니다.

이 개인정보처리방침의 공개 페이지는 GitHub Pages에 게시됩니다. 이용자가 해당 페이지를 열면 GitHub가 보안 목적으로 방문자의 IP 주소를 기록합니다. 이는 앱의 자동 환율 조회와 별개의 웹페이지 접속입니다. GitHub Pages 정보 수집 안내와 GitHub 개인정보처리방침을 확인할 수 있습니다.

6. 보유 및 파기

기기 내부에 저장된 설정, 자동 환율 정보·조회 기록 및 구매 권한 캐시는 앱 데이터 삭제 또는 앱 삭제 시 제거됩니다. 일시적인 계산 상태는 계산 초기화 또는 앱 종료 시 제거됩니다.

ONE Store가 관리하는 계정 및 구매·결제 기록은 ONE Store의 개인정보처리방침과 관계 법령에 따라 보관·파기됩니다.

호스팅 제공자가 처리하는 통신정보는 서비스 제공·보안 및 법적 의무 이행에 필요한 기간 동안 해당 제공자의 정책과 계약에 따라 보관·파기됩니다. 운영자는 이 기록에 별도의 고정 보유기간을 정하지 않습니다. 관련 기준은 OpenAI의 데이터 처리 부속약정과 Cloudflare 개인정보처리방침에서 확인할 수 있습니다. GitHub Pages 방문 기록에는 GitHub의 보유·파기 기준이 적용됩니다.

7. 이용자의 권리와 정보 삭제 방법

자동 환율 사용 여부는 앱의 환율 설정에서 변경할 수 있습니다. 자동 환율을 꺼도 수동 환율 입력과 계산 기능은 사용할 수 있습니다.

이용자는 다음 방법으로 앱의 로컬 정보를 직접 삭제할 수 있습니다.

  • Android 설정 > 애플리케이션 > 서학개미 계산기 > 저장공간 > 데이터 삭제
  • 기기에서 앱 삭제

앱 데이터 삭제 후에도 ONE Store 계정에 남은 관리형 인앱상품 구매 기록은 앱을 다시 실행하거나 구매 복원 기능을 사용할 때 다시 조회될 수 있습니다. 결제 내역의 정정·환불 등 ONE Store가 관리하는 정보는 ONE Store 고객지원과 관련 절차를 이용할 수 있습니다.

8. 아동의 개인정보

앱은 만 14세 미만 아동을 주 이용자로 설계하지 않았으며, 운영자가 아동의 개인정보를 의도적으로 수집하지 않습니다. 인앱결제는 ONE Store의 계정·결제 및 보호자 통제 절차를 따릅니다.

9. 정보 보호 조치

앱은 Android 백업을 비활성화하고 평문 네트워크 통신을 허용하지 않도록 구성합니다. 운영자는 앱 권한을 기능에 필요한 범위로 제한하고 ONE Store 인앱결제 SDK를 안전하게 관리합니다.

자동 환율 파일은 크기·형식·전자서명·기준일과 버전을 검증한 뒤 값으로만 사용합니다. 파일에 포함된 코드나 링크를 실행하지 않으며, 검증에 실패하면 해당 값을 적용하지 않습니다.
